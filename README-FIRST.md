# SIMS Site Strategist v0.1.18

v0.1.17の実機試験合格版を基準に、Code.gsの収集進捗ダイアログのポーリング条件のみ変更しました。

## 適用
Apps ScriptのCode.gsを全置換して保存し、スプレッドシートを再読み込みします。SiteConfigの製品バージョンは既存のバージョン同期処理により0.1.18に更新されます。

## 変更
- 収集中・自動再開待ちのみ15秒間隔で進捗を確認。
- 完了・エラー・履歴なしの場合は自動確認を停止。
- 手動更新は引き続き利用可能。手動確認で収集中と判定されれば自動確認を再開。
- ダイアログを閉じた場合はタイマーを停止。

GSC収集処理・Evidence・Googleドライブのフォルダー構成は変更しません。
次段階のEvidence統合・起動時差分収集は未実装です。実機試験未実施。
